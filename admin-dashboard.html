How to Embed a Stream
Option 1 — iFrame URL: Copy the stream embed URL (e.g. from a CDN, embed.example.com/live/match123) and paste it in the stream URL field of any match. The player will load it directly in an iframe.

Option 2 — YouTube Live: Use the YouTube embed URL format: https://www.youtube.com/embed/VIDEO_ID?autoplay=1

Option 3 — Raw HTML: Paste your full <iframe> embed code for Dailymotion, Twitch, or any custom stream provider.

Option 4 — HLS: For HLS / M3U8 streams, integrate video.js or hls.js into your site for native playback.
